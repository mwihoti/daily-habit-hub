# FitTribe Ad Concepts

This folder contains campaign concepts for five visual ads focused on FitTribe's core product features.

Concepts:

1. Daily Check-Ins and streak tracking
2. Personal trainers across Nairobi
3. Community accountability feed
4. Web3 rewards and NFT badges
5. All-in-one fitness habit platform

Use these concepts to keep messaging aligned across static ads, landing pages, and social posts.
